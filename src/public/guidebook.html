시작하기

준비, 생성, 배치, 지시, 확인 순서로 진행하세요.

5단계
01

기본 자료 준비

필요하면 「스킬 등록」과 「페르소나 템플릿」에서 공통 설정을 준비하세요. Codex 인증은 서버의 CODEX_HOME에서 별도로 준비합니다.

02

AI 직원 생성

이름·담당 업무·관리/실무 역할과 모델·페르소나·기본 스킬·작업 위치를 입력합니다. 첫 세션도 함께 생성됩니다.

03

조직에 배치

조직 목록에서 조직도를 열고 미배정 AI 직원을 배치합니다. 직속 관계와 관리 AI의 호출 권한은 별도로 설정합니다.

04

업무 지시

「업무 지시」에서 관리 AI에게 목적과 결과 보고 확인 항목을 등록합니다. 저장만으로 Task가 자동 생성되지는 않습니다.

05

기록 확인

업무 지시 상태·결과 보고, Task 이력, 각 AI의 업무 일지, 세션 대화를 각각 확인합니다.

작업 공간 화면

직원·조직 설정과 업무 지시, AI 기록은 별도 화면입니다.

일상 작업

01AI 직원

AI 직원과 첫 세션을 함께 생성합니다. 세션 표시명은 실제 Codex 세션 ID와 다르며, 실제 ID는 CLI 실행 후 기록됩니다. 모델 변경은 다음 실행부터 적용됩니다.

모델 변경기본 페르소나기본 스킬

02조직·직원

조직 목록에서 조직도를 열고 미배정 AI 직원을 배치합니다. 이미 배치된 직원을 중복 선택할 수 없습니다.

인사이동과 직속 관리 AI 지정은 호출 권한 부여와 별개입니다. 관리 AI별로 허용할 작업 AI를 명시적으로 설정하세요.

03업무 지시

사용자가 관리 AI에 요청하는 진입점입니다. 제목·요청 내용·결과 보고에서 확인할 사항을 등록하고 상태와 보고서를 확인합니다.

저장만으로 Task가 생성되지는 않습니다. 관리 AI의 수동 실행이나 일정이 별도로 필요합니다.

04Task 이력·업무 일지

끝이 정해진 Task의 진척도는 근거가 확인된 완료 조건의 가중치로 계산합니다. 계속 업무·정기 점검에는 전체 진척도 대신 실행 회차·미수행·파생 Task를 표시합니다.

업무 일지는 AI 직원이 자신의 작업 내용·근거·다음 행동을 남기는 기록입니다. 사용자 화면에서는 읽기 전용입니다.

05세션 대화

현재·과거 세션의 공개 대화 이벤트를 확인합니다. Runner 이벤트와 재색인한 Codex JSONL의 공개 메시지가 표시되며, 로그 형식이나 누락에 따라 전체 수집은 보장되지 않습니다.

061:1 면담

관리 AI와 작업 AI 모두와 별도 면담 세션에서 대화할 수 있습니다. 면담 세션에는 업무용 System MCP를 전달하지 않습니다. 후속 업무는 「업무 지시」에서 관리 AI에게 요청하세요.

자주 묻는 질문

비슷한 항목의 역할을 구분합니다.

AI 직원과 세션을 따로 만드나요?

새 AI 직원을 만들 때 첫 세션도 함께 생성합니다. 조직 배치는 그다음에 진행합니다. 세션 표시명은 Codex가 발급하는 실제 세션 ID가 아닙니다.

직속 관리 AI가 있으면 해당 직원을 호출할 수 있나요?

아니요. 조직도의 직속 관계와 호출 권한은 별개입니다. 관리 AI에게 허용한 작업 AI만 호출할 수 있습니다.

업무 지시를 저장하면 Task가 시작되나요?

아니요. 업무 지시는 DB에 등록되지만, 저장만으로 Task가 생성되지는 않습니다. 관리 AI의 실행이나 일정이 별도로 필요합니다.

업무 일지는 누구를 위한 기록인가요?

기록한 AI 직원이 다음 실행에서 같은 작업을 이어가기 위한 진척 메모입니다. 작업 요약, 완료 사항, 근거, 미완료 항목과 다음 행동을 남깁니다.

정기 점검에 전체 진척도가 없는 이유는 무엇인가요?

종료 시점이 없어 완료 비율의 분모를 정할 수 없기 때문입니다. 대신 실행 회차와 미수행 상태, 파생된 미해결 Task, 다음 일정을 표시합니다.

모델별 요금을 등록하면 청구액을 알 수 있나요?

아니요. 현재는 수동 단가만 저장합니다. 토큰 사용량 수집, 비용 추정, 실제 청구 내역 대조는 구현되지 않았습니다.

운영 범위와 저장 위치

실제 기록과 미구현 기능을 구분하세요.

미구현 범위: 예약 인사이동, 승인 기반 외부 쓰기, 다중 사용자 인증, 실제 요금 계산은 제공하지 않습니다. Codex CLI와 사내 이용 제한을 결합한 시험도 수행하지 않았습니다.
저장 위치: 운영 데이터의 기준 원본은 서버의 SQLite DB입니다. 브라우저를 닫아도 저장된 기록은 유지됩니다. 관리자 토큰은 이 탭의 세션 저장소에만 보관합니다.
